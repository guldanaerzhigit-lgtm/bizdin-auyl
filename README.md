# BIZDIŃ AÝYL

**Бір аудан. Бір қауым. Бір желі.**

A mobile-first community social network for residents of the Jangeldin District, Kostanay Region, Kazakhstan.

## Current status
Initial UI prototype built with React and Vite. The current feed uses demo content and local component state; authentication, database persistence, media uploads, messaging and moderation will be connected in later milestones.

## Stack
- React + Vite
- Cloudflare Pages (frontend hosting)
- Cloudflare Workers + D1 (API and relational data)
- Cloudflare R2 (media storage)
- Firebase Authentication (Google and phone sign-in)

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Product principles
- Kazakh and Russian interface
- Mobile-first, accessible design
- Community focused on the Jangeldin District
- Privacy, safety and clear moderation tools
